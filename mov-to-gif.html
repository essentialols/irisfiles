How MOV to GIF conversion works

IrisFiles decodes the MOV with the browser's video engine, samples frames at the frame rate you choose, resizes them to the selected width, and encodes an animated GIF in the tab. The encoder samples colors from the clip to build one 256-color palette and skips nearly identical consecutive frames while extending their display time. That keeps simple screen recordings and static moments smaller without uploading the video.

How to convert MOV to GIF

  1. Add a MOV file and wait for the preview to appear.
  2. Choose the part of the video you want with the start and end controls. The current interface exposes up to the first 60 seconds.
  3. Set the output width from 160 to 800 pixels and frame rate from 4 to 20 frames per second.
  4. Click Convert to GIF and download the animated result.

Higher-quality MOV to GIF settings

GIF can show only 256 colors, so it cannot preserve the full color range of a modern MOV video. A wider output keeps more detail, while a higher frame rate makes motion smoother. Both increase file size. For interface demos and short screen recordings, a moderate width and around 8 to 12 frames per second is often a practical starting point.

Why can the GIF be larger than the MOV?

Modern MOV video codecs compress motion much more efficiently than GIF. A GIF stores a sequence of palette-based images rather than a modern inter-frame video stream, so even a short GIF can become larger than the source clip. Trim aggressively and reduce width or frame rate when file size matters.

What happens to the MOV audio?

GIF has no audio track. IrisFiles uses the video frames and does not include sound in the output. If you need a smaller video that keeps audio, use a video format instead of GIF.

iPhone, QuickTime, Mac, and Windows MOV files

MOV is a container, so compatibility depends on the video codec inside it. IrisFiles can convert a MOV only when the browser can decode that codec. If your MOV does not preview, try another modern browser or use MOV to MP4 when that workflow is compatible with the source. For other browser-compatible video files, see Video to GIF or MP4 to GIF.

Private MOV to GIF conversion

Frame extraction, resizing, palette generation, and GIF encoding all happen in the browser tab. The MOV itself is not uploaded to an IrisFiles conversion server. More implementation detail is available on the About IrisFiles page.
