How to convert AVI to WebM

  1. Drop a single AVI file onto the page, or click to browse and select one.
  2. Click Convert. IrisFiles loads its browser-based FFmpeg engine and re-encodes the video locally.
  3. Save the finished WebM file once it appears.

How the conversion works

IrisFiles runs FFmpeg.wasm, a build of FFmpeg compiled to WebAssembly, directly in this page. It decodes your AVI file and re-encodes the video with FFmpeg's libvpx encoder and the audio with libvorbis, at fixed settings: CRF 30, a 1 Mbps video bitrate cap, and Vorbis quality level 4. These settings are not adjustable on this page. There is no resolution, frame rate, trim, or bitrate control here, only the file itself.

WebM is a container, not a codec

WebM is a container format, the same way AVI is a container format. What is actually inside the container is what determines compatibility and file size. This converter writes VP8 video, not the newer VP9. VP8 is older and generally less efficient than VP9 at a given quality, so a VP8 WebM file can end up larger than a VP9 WebM file of the same source, and playback support for VP8 is broad but not identical to VP9 support.

AVI to WebM conversion and video quality

AVI files are usually already compressed with a lossy video codec. Converting to WebM means decoding that codec and encoding a new VP8 stream, a lossy-to-lossy re-encode, so some generational quality loss is expected even when the result looks close to the source. The 1 Mbps video bitrate cap is fixed regardless of resolution or motion: a high-resolution or high-motion source, such as fast camera pans or action footage, can come out visibly blockier or softer than the original, because 1 Mbps is not much data to preserve detail at higher resolutions or with complex motion.

Limits and failure modes

Videos longer than 10 minutes are rejected before conversion starts. There is no configured file size limit, but very large files (IrisFiles shows an advisory warning above 200MB) can be slow to convert or exhaust your browser's available memory, since the source video and intermediate frames are held in memory during conversion; memory, not a size cap, is the real ceiling. This converter handles one AVI file at a time; there is no batch or ZIP output here. If conversion fails, the message "Conversion failed. The file may be corrupted or use an unsupported codec." usually means the file is not the AVI container FFmpeg expects, even if its extension says .avi. If the engine itself cannot load, you'll see "Failed to load video converter. Check your internet connection." since the FFmpeg.wasm engine is fetched from a CDN the first time you use it.

When not to use this converter

If your priority is playing the result on as many devices and players as possible, AVI to MP4 is the safer choice: H.264 in an MP4 container plays almost everywhere, while VP8 in WebM does not have the same universal support. If your source is already an MP4 and you only need a different container, MP4 to WebM is the more direct route.

Privacy

Your AVI file is read locally and converted inside this page; it is not uploaded anywhere. The only network request involved in a conversion is a one-time download of the FFmpeg.wasm engine from a CDN, which your browser then caches. Your video itself never leaves your device.

You do not have to take that on trust. Your browser's network inspector will show you every request this page makes while it converts a file. We wrote up how to verify that a file converter does not upload your files, including what we observed on this exact page and what that check does not prove.
