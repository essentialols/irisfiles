How to convert M4A to WAV

  1. Add an M4A file, or add several files for a batch conversion.
  2. IrisFiles decodes the M4A audio locally in your browser and writes a WAV file.
  3. Download each WAV individually, or download a ZIP when multiple conversions finish.

Why convert M4A to WAV?

M4A is commonly used for compressed audio, voice recordings, music-library files, and exports from Apple software. WAV is widely accepted by audio editors, digital audio workstations, transcription software, samplers, and older applications that expect uncompressed PCM audio. Converting first can make an M4A easier to edit without relying on M4A codec support in the next application.

M4A is a container, not one audio codec

An .m4a file can contain different kinds of audio, most commonly AAC and sometimes ALAC. IrisFiles uses the browser's own audio decoder, so the important question is whether that browser can decode the codec inside your M4A. DRM-protected media and files using a codec the browser does not support will fail instead of producing a misleading WAV.

What does IrisFiles put in the WAV file?

IrisFiles uses the browser's Web Audio API to decode the M4A and writes the result as 16-bit PCM WAV. The WAV keeps the decoded channel count. Its sample rate is the rate produced by the browser's audio decoder, so a browser may resample some inputs during decoding. Because WAV is uncompressed, the output will usually be much larger than the original M4A.

M4A vs WAV: what actually changes?

  • Compression: M4A often contains compressed AAC; the IrisFiles WAV output is uncompressed PCM.
  • Editing compatibility: WAV is accepted by nearly every audio editor and DAW.
  • File size: WAV is usually much larger because it stores PCM samples directly.
  • Quality: converting a lossy source to WAV does not recover information already discarded by AAC.

Does M4A to WAV improve quality?

No. If the M4A contains lossy AAC audio, information discarded during the original AAC encoding cannot be recovered. WAV avoids adding another lossy codec after decoding, which is useful for editing, but it does not make a lossy source higher fidelity. If you only need a smaller, widely playable file, M4A to MP3 may be a better fit.

Private batch M4A to WAV conversion

You can queue up to 50 files. IrisFiles runs up to two audio conversions at a time and packages multiple finished files into a ZIP on your device. No audio file is uploaded to an IrisFiles conversion server. More implementation detail is available on the About IrisFiles page.
