How to convert HEIC to PDF

  1. Add one or more HEIC or HEIF photos from your device.
  2. Check that the photos appear in the order you want them in the PDF. Pages follow the order the files were added.
  3. Click Convert to PDF, then download the finished document.

Combine multiple HEIC photos into one PDF

IrisFiles can combine up to 50 HEIC photos in a single conversion. This is useful for turning a group of iPhone photos, scanned receipts, forms, or reference images into one document instead of creating a separate PDF for every photo. The current page does not offer drag-to-reorder controls: if you need a different page order, remove a file and add it again in the position you want before converting.

HEIC, HEIF, and PDF are different kinds of formats

HEIF is an image-container format, while HEIC is a common extension for HEIF images encoded with HEVC. PDF is a document format that can contain one or many pages. IrisFiles accepts both .heic and .heif files here and turns each input image into one page of a single PDF.

What happens to image quality and page size?

HEIC images are decoded in your browser and converted to JPEG before they are embedded in the PDF. That means HEIC to PDF is not a lossless archival transformation and small compression differences are possible. IrisFiles keeps the decoded image's pixel dimensions, and each PDF page is sized to that image rather than forcing every photo onto A4 or US Letter paper.

The current converter does not add margins, rotate pages, or normalize them to a paper size. That makes it useful when you want the PDF page to follow the photo itself. If you need an editable image instead of a document, use HEIC to JPG or HEIC to PNG. If your photos are already JPG files, the dedicated JPG to PDF converter skips the HEIC decoding step.

HEIC to PDF on iPhone, Mac, Windows, and Android

The HEIC decoder runs with WebAssembly inside the browser, so the operating system does not need its own HEIC converter. A modern browser with WebAssembly support is required. The conversion itself stays on your device; the browser only downloads the open-source code needed to perform the work.

How the private conversion works

IrisFiles decodes HEIC in the tab, then uses a browser-loaded PDF library to create the document locally. Your source photo bytes are not posted to an IrisFiles conversion API. You can read more about the implementation and third-party libraries on the About IrisFiles page.
